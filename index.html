Accessibility First Design

Spectra is built with accessibility at its core. The interface uses soft colors, readable fonts, and carefully selected contrast levels to reduce strain for users with visual impairments.

The extension supports keyboard navigation, voice commands, and customizable reading modes to make browsing easier.
